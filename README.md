# Advanced Statistics — Probabilistic Machine Learning

**Course 367-2-5561 · Ben-Gurion University of the Negev · Semester 2027-1 · Instructor: Opher Donchin**

This repository contains the materials released to students in this course: the syllabus, lecture slides, student notebooks, datasets, and instructions. Materials are added as they are released, so something you expect may not be here yet.

## Finding lectures and notebooks

Released materials are collected in this repository as the semester progresses. Check the course site (Moodle) for announcements of what has been released.

## Running the notebooks

You will generally run the Jupyter notebooks in [Google Colab](https://colab.research.google.com/), which needs only a browser and a Google account. Running locally is also possible where a notebook supports it; any local requirements will be stated in that notebook or its instructions.

## Submitting work

Completed InClass notebooks are submitted **through Moodle by Wednesday at 23:59 Israel time**. Do not submit through GitHub (no pull requests, issues or commits to this repository).
